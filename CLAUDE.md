# GoXLR Studio

Selvstændig Windows-app (Tauri 2: Rust + vanilla JS) der erstatter GoXLR Utility/TC-Helicons app, Equalizer APO, Peace og AutoHotkey – ét program. Kun TC-Helicons USB-driver skal være installeret. Svar brugeren på dansk.

## Arkitektur
- `public/` – UI (ES-moduler, ingen build). `js/api.js` taler med GoXLR-motoren (via Tauri-kommandoen `daemon_request` eller WebSocket i browser) og falder tilbage til `js/demo.js` når der ingen motor er.
- `src-tauri/goxlr-engine/` – **GoXLR-motoren i appen**: GoXLR Utility's daemon (v1.2.4, MIT) som lib-crate (ændringer markeret `GoXLR Studio:`, liste i dens README): `run()` (blokerende, kan startes igen), `request_stop()`, `is_ready()`, `set_activate_hook()`; intet bakke-ikon, ingen GoXLR Utility-UI (Activate/OpenUi → vores vindue), web-UI erstattet af en lille side, autostart-link slået fra, "kører allerede" = anden `goxlr-daemon.exe`. Søster-crates (usb/ipc/types/audio/profile/scribbles) som git-deps på tag `v1.2.4`; reqwest med native-tls og `pest` låst til 2.8.3 (så `cargo check` til Windows virker uden MSVC). Kun Windows-afhængighed.
- `src-tauri/src/daemon_host.rs` – kører motoren på tråden `goxlr-engine` i appen (`start_and_wait`, `stop` ved Afslut, `last_error` med danske forklaringer, event `engine-stopped`); 0,8 s efter appstart overtages en kørende GoXLR Utility (`take_over`: stopper goxlr-daemon/launcher/utility-ui, flytter `GoXLR Utility.lnk` til backup) og 0.3.x' udpakkede motor (`%LOCALAPPDATA%\GoXLR Studio\engine`) stoppes og slettes. Samme profil-/indstillingsmapper og API (127.0.0.1:14564) som GoXLR Utility (`%APPDATA%\GoXLR-on-Linux\GoXLR-Utility`); log i GoXLR Utility's log-mappe (`goxlr-daemon.log`).
- `src-tauri/src/daemon.rs` – WebSocket-klient til motoren (`ws://127.0.0.1:14564/api/websocket`), JSON-patches sendes som `daemon-patch`-events.
- `src-tauri/src/engine.rs` – **indbygget EQ-motor**: Equalizer APO 1.4.2's motorfiler (GPL, uændrede, hentet + SHA-256-tjekket i CI, indlejret via env `ENGINE_DIR`) installeres i `C:\Program Files\GoXLR Studio Engine` og registreres (regsvr32 + port af Equalizer APO's `DeviceAPOInfo` install/uninstall: FxProperties, `Child APOs`, ejerskab). `ConfigPath` peger på `%ProgramData%\GoXLR Studio\engine` (overvåges af motoren → ændringer høres straks). Alt med admin kører i en elevated kopi af exe'en: `--engine-task <task.json> <result.json>` (`Task`: install/set-devices/test/uninstall/use-external/restore-external). Efter install/set-devices (og ved `test`) **testes udgangene** som i Equalizer APO's Device Selector: `DeviceTestPipeName` sættes, pipe `\\.\pipe\GoXLRStudioEngineTest` lytter, lydtjenesten genstartes, hver udgang åbnes (IAudioClient), motoren melder PreMix/PostMix "Initialize"; udgange uden svar prøver SFX/EFX → SFX/MFX → LFX/GFX (`TaskResult.tests`, UI-badges "kører"/"ikke indlæst", knap "Test EQ-motoren", gemmes i store-nøglen `engine-test`). En separat Equalizer APO tages backup af (`%ProgramData%\GoXLR Studio\apo-backup-*`) og afinstalleres stille før installation.
- `src-tauri/src/apo.rs` – renderer EQ til APO-syntaks og skriver `config.txt` i motorens mappe; finder gamle Peace/APO-presets (separat installation eller backups).
- `src-tauri/src/migrate.rs` – Overflytning: scanner AutoHotkey (inkl. Startup-genveje), TC-Helicon-profiler, APO/Peace; fuld backup til `%APPDATA%\GoXLR Studio\backup\<tid>`; liste over gamle programmer (Uninstall-nøgler) med kategori keep/replace/engine/check og start af deres afinstallation.
- `src-tauri/src/audio.rs` – Windows Core Audio: list enheder + skift standardenhed (IPolicyConfig). `apps.rs` – lyd pr. app.
- `src-tauri/src/lib.rs` – kommandoer, bakke-ikon (rød prik ved mute), frie globale genveje (`set_hotkeys`), luk-til-bakke, autostart, `helper_main` (CLI-tilstande).
- `src-tauri/src/osd.rs` – OSD-vindue (`public/osd.html`), vises uden at tage fokus; springes over når hovedvinduet har fokus.
- `src-tauri/src/api.rs` – lokalt HTTP-API (token påkrævet): `/state`, `/actions`, `/action/<id>` → event `api-action`.
- `src-tauri/src/update.rs` – auto-opdatering fra GitHub-releases (kun URL'er under repoets releases/download, SHA-256 fra GitHubs `digest`), installer `/S` eller udskift portable exe.
- `src-tauri/src/keys.rs` – `send_keys` (SendInput af en genvej) og `discord_running`. `meters.rs` – peak-niveauer til VU-metre.
- `public/js/extras.js` – rene hjælpere (enhed-navne-fallback, crossfeed/loudness, AutoEQ, versioner, app-triggers, AutoHotkey-parser `parseAhk`, `faderLeds`, `micMutedForChat`) med tests i `tests/extras.test.mjs`.
- `THIRD-PARTY-NOTICES.md` + `licenses/` – licenser for de indlejrede motorer; release vedlægger `EqualizerAPO-src-1.4.2.zip`.
- Kommando-/statusformater kommer fra GoXLR Utility: `ipc/src/lib.rs` og `ipc/src/device.rs` i github.com/GoXLR-on-Linux/goxlr-utility.

## Test
- `node --test tests/*.test.mjs` – EQ-matematik, APO-parser, JSON-patch, extras (AHK-import, AutoEQ, opdatering m.m.).
- `cd src-tauri && cargo test --lib` (Linux kræver webkit2gtk/gtk-dev) – motor-registrering, migrering, API.
- `STUDIO_PORT=14600 node server.js` – UI i browser (demo-tilstand uden daemon; `?mini` = GoXLR Mini; motorer og overflytning simuleres i `native.js`).
- Skærmbilleder til README: `node scripts/screenshots.cjs docs/screenshots` mens serveren kører (Playwright; reducér PNG'erne til 256 farver bagefter). README beskriver hvad appen er og kan, med billederne.
- Rust: `cd src-tauri && cargo check --target x86_64-pc-windows-msvc` (tjekker også GoXLR-motoren). Med indlejret EQ-motor: sæt `ENGINE_DIR` (mappe med de 8 motorfiler) og `ENGINE_VERSION`. Fuldt byg sker i GitHub Actions (`.github/workflows/build.yml`).

## Regler
- Ingen personlige data i repoet; commits med noreply-identitet.
- Firmware til GoXLR'en røres ikke (lukket, risiko for brick).

## Status og næste skridt
Version 0.4.1 – ét program. Færdigt:
- 0.4.1 (fejl 1): EQ-motorens **registrering tjekkes og repareres** (`engine::registration()` læse-tjek uden admin: CLSID'ernes InprocServer32 → vores DLL, AudioProcessingObjects, `DisableProtectedAudioDG=1`; ren `classify_registration` med tests; `ensure_engine_registered` i Test/SetDevices/Install; skema `GoXLRStudioEngineSchema`=2 i `HKLM\SOFTWARE\EqualizerAPO`). Opstart: banner + automatisk reparation én gang pr. app-version (`prefs.engineRepairTried`); EQ-side og Overflytning viser "skal repareres". Årsag: `_?=` til Equalizer APO's afinstaller blev citeret, så den kørte videre fra %TEMP% og afregistrerede motoren (nu `raw_arg` + venter på at dens Uninstall-nøgle forsvinder). Browser-demo: `?brokenengine`.
- 0.4.0: **GoXLR-motoren kører inde i GoXLR Studio** (ingen separat `goxlr-daemon.exe`, intet GoXLR Utility-bakkeikon eller -UI; i 0.3.x viste `--disable-tray true` faktisk bakkeikonet, fordi GoXLR Utility gemmer værdien som "vis bakke-ikon"). **EQ-motoren tester sig selv** og finder den måde, den bliver indlæst på (brugeren rapporterede at EQ'en "gør intet" – 0.3.x gættede LFX/GFX og testede aldrig).
- Indbygget GoXLR-motor og EQ-motor (se Arkitektur), siden **Overflytning** (backup, AHK→genveje, Peace-presets, TC-Helicon-profiler, "husk lyd pr. app", afinstallér gamle programmer; driveren markeres BEHOLD), EQ-motor-kort med valg af udgange.
- 0.3.3: **ét program**: ved start overtager GoXLR Studio fra en kørende GoXLR Utility (`daemon_host::take_over`: stopper goxlr-daemon/launcher/utility-ui uden for vores sti, flytter `GoXLR Utility.lnk` fra Startup til backup, starter den indbyggede motor; starter GoXLR Utility igen hvis vores fejler). Pref `builtinEngine` (standard til), events `engine-takeover`/`engine-takeover-failed`, kommando `daemon_takeover`. NSIS-hook `src-tauri/windows/hooks.nsh` kører `--engine-uninstall` ved afinstallation (ikke ved `/UPDATE`): fjerner den udpakkede GoXLR-motor og EQ-motoren. Auto-opdatering kører installer med `/S /UPDATE`.
- 0.3.2: VU-metre ved hver fader (`meters.rs`: baggrundstråd læser Windows' `IAudioMeterInformation` for alle aktive endpoints ~30 Hz mens UI'et spørger; `audio_levels`; mic fra daemonens `GetMicLevel`; kanal→GoXLR-udgang via `channelEndpoint`); EQ-motor kan sættes på "en anden måde" (`mode`: lfx-gfx/sfx-efx/sfx-mfx = Equalizer APO's fejlfindingsmuligheder) hvis EQ ikke høres; Lyd pr. app: "Tilføj regel" for apps der ikke kører, "Husk" vælger processen der har en enhed (Discord).
- 0.3.1: mixerens faders tegnes som hardwarens 15 LED'er (`faderLeds`: `colour_one` = over knappen, `colour_two` = under; Gradient blender under knappen), demo matcher Mini-layoutet; Discord-mute-synk (`discord.js`: når GoXLR-mic-mute mod voice chat skifter, trykkes Discords "Toggle Mute"-genvej via `send_keys`/SendInput, standard Ctrl+Shift+Alt+D, kun hvis Discord kører); dansk README med download-link.
- Fra 0.2: genveje, lyd pr. app, bakkemenu, hurtig-skift, preset-chips, AutoEQ, EQ følger profil, crossfeed/loudness, OSD, API, backup, Diagnose, auto-opdatering.

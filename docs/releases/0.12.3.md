## GoXLR Studio 0.12.3

Rettelse: efter Windows-start eller en opdatering kunne GoXLR Studio vise profilen "Default" uden dine profiler – som om alt skulle sættes op forfra. Intet var slettet.

- **Årsagen:** en ekstra GoXLR Studio, der kørte som administrator eller som en anden Windows-konto – typisk startet af en planlagt opgave "med højeste rettigheder" eller af Windows 11's administrator-beskyttelse. Den blev ikke opdaget af tjekket for, om appen allerede kører, og heller ikke stoppet af installeren. Den tog GoXLR-motoren med den anden kontos (tomme) indstillinger, og den holdt exe-filen låst, så en opdatering ikke blev installeret.
- **Nu:** en GoXLR Studio, der startes som administrator, mens din egen kører, lukker straks sig selv. Kører der allerede en anden, siger fejlfinderen det og har knappen "Luk den anden GoXLR Studio" (Windows beder om administrator-adgang). Bagefter starter appen sin egen motor med dine profiler.
- **Motor uden dine indstillinger:** kører motoren med profilen "Default" og uden profilfiler, selv om dine indstillinger siger noget andet, genstarter appen den selv og skriver det under "Seneste hændelser".
- **Start med Windows:** ved start med Windows venter GoXLR-motoren nu op til et par minutter på TC-Helicons driver, hvis den er længe om at blive klar.
- **Opdatering:** hjælperen stopper andre GoXLR Studio-processer før installationen, og bagefter tjekker den, at exe-filen faktisk har fået den nye version. Hvis ikke, siger appen det i stedet for "opdateret".

**Det skal du gøre:** Starter du GoXLR Studio med en planlagt opgave, så slet den – appen starter selv med Windows (Indstillinger → Start med Windows). Viser appen et banner om en anden GoXLR Studio, så tryk "Luk den anden GoXLR Studio".

---

### English

Fix: after Windows start or an update, GoXLR Studio could show the profile "Default" without your profiles – as if everything had to be set up again. Nothing was deleted.

- **The cause:** an extra GoXLR Studio running as administrator or as another Windows account – typically started by a scheduled task "with highest privileges" or by Windows 11's administrator protection. It was not found by the check for an app that already runs, nor stopped by the installer. It took the GoXLR engine with the other account's (empty) settings, and it kept the exe file locked, so an update was not installed.
- **Now:** a GoXLR Studio started as administrator while your own runs closes itself at once. If another one already runs, the troubleshooter says so and has the button "Close the other GoXLR Studio" (Windows asks for administrator access). Afterwards the app starts its own engine with your profiles.
- **Engine without your settings:** if the engine runs with the profile "Default" and no profile files although your settings say otherwise, the app restarts it by itself and writes it under "Recent events".
- **Start with Windows:** when started with Windows, the GoXLR engine now waits up to a few minutes for TC-Helicon's driver if it is slow to get ready.
- **Update:** the helper stops other GoXLR Studio processes before installing, and afterwards checks that the exe file really has the new version. If not, the app says so instead of "updated".

**What you need to do:** If you start GoXLR Studio with a scheduled task, delete it – the app starts with Windows by itself (Settings → Start with Windows). If the app shows a banner about another GoXLR Studio, press "Close the other GoXLR Studio".

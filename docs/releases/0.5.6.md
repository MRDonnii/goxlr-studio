## GoXLR Studio 0.5.6

**Mobil-fjernbetjening** (Indstillinger → Lokalt API): slå API til og "Tillad fra andre enheder på netværket", og kopiér linket til telefonen (samme wifi). Siden har mikrofon-mute, profiler, scener, EQ-presets og lydstyrke – gem den på hjemmeskærmen.

**OBS** (Indstillinger → OBS): GoXLR Studio kan skifte OBS-scene – fra genveje, Stream Deck, automatik og Home Assistant – og OBS-scenen kan følge GoXLR-profilen. Handlingen **"Stream-sikker musik"** tager Music-kanalen ud af stream-mixet, så streamen ikke får musik, du ikke må bruge.

**Del mikrofonindstillinger** (Mikrofon): "Del mine indstillinger…" gemmer gain, EQ, gate, kompressor og de-esser som én fil, som en ven kan hente ind med "Brug delte indstillinger…". Det kan fortrydes.

**Diagnose-rapport:** rapporten har nu Lydtjek-fund, den sidste EQ-motor-test og status for Home Assistant og OBS – uden adgangskoder og tokens – og kan gemmes som fil.

**Det skal du gøre:** Ingenting. Vil du bruge OBS, skal WebSocket-serveren slås til i OBS (Værktøjer → WebSocket Server Settings). Windows Firewall spørger første gang, du tillader API'et fra netværket.

---

### English

**Mobile remote** (Settings → Local API): turn on the API and "Allow from other devices on the network", and copy the link to your phone (same Wi-Fi). The page has mic mute, profiles, scenes, EQ presets and volume – save it to your home screen.

**OBS** (Settings → OBS): GoXLR Studio can switch OBS scenes – from hotkeys, Stream Deck, automation and Home Assistant – and the OBS scene can follow the GoXLR profile. The action **"Stream-safe music"** takes the Music channel out of the stream mix, so your stream doesn't get music you may not use.

**Share mic settings** (Mic): "Share my settings…" saves gain, EQ, gate, compressor and de-esser as one file that a friend can load with "Use shared settings…". It can be undone.

**Diagnostics report:** the report now includes sound check findings, the last EQ engine test and the status of Home Assistant and OBS – without passwords and tokens – and can be saved as a file.

**What you need to do:** Nothing. To use OBS, turn on the WebSocket server in OBS (Tools → WebSocket Server Settings). Windows Firewall asks the first time you allow the API from the network.

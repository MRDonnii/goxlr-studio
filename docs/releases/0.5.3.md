## GoXLR Studio 0.5.3

**Nyt: Lydtjek** (ny side i menuen). Den finder Windows-indstillinger, der ændrer eller skjuler lyden uden om GoXLR Studio, og retter dem med ét klik:
- **Windows skruer ned for spil og musik under opkald.** Som standard sænker Windows andre lyde med 80 %, når Discord bruger mikrofonen. Det kan slås fra her. Din gamle indstilling gemmes først, så "Fortryd" kan sætte den tilbage.
- GoXLR-udgange og Chat Mic, der er muted eller skruet ned i Windows.
- Standardenheder, der går uden om GoXLR'en, og lydformatet (fx 48 kHz · 24 bit).
- EQ-motorens tilstand.
- Råd til Discord, så den ikke kæmper mod GoXLR'ens noise gate og kompressor.

**Bedre lyd ud:**
- **Klip-beskyttelse** og "Auto" holder nu en EQ med løft på −0,5 dB i stedet for 0 dB, fordi lydtoppe kan ligge lidt over kurven.
- **Mono og balance** under Lytte-forbedringer, fx til én øresnegl eller hvis du hører dårligere på det ene øre.

**Det skal du gøre:** Åbn **Lydtjek** én gang og ret det, den foreslår. Resten sker af sig selv.

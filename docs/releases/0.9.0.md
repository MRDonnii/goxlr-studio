## GoXLR Studio 0.9.0

- **Plugin til Elgato Stream Deck – med status:** tasterne lyser, når det, de styrer, er slået til (fx rød ved muted mikrofon, eller når en profil eller et EQ-preset er i brug). Drejeknapperne på Stream Deck + styrer en kanals lydstyrke og mute. Hent `GoXLR-Studio.streamDeckPlugin` herunder eller fra Stream Deck-siden i appen, og dobbeltklik på den.
- **Home Assistant:** ChatMix, mikrofon-limiter, "Spiltilstand aktiv" og en "Gem lydklip"-knap.
- **Mobil-fjernbetjeningen:** ChatMix, limiter og "Gem lydklip".
- **Rene stemmer i chatten** siger til, hvis Chat-udgangen ikke kører 48 kHz.
- Diagnose-rapporten viser, hvilke af de nye funktioner der er slået til.
- Nye billeder i README af Sampler, GoXLR-indstillinger og ChatMix.

**Det skal du gøre:** Ingenting. Vil du bruge Stream Deck-pluginnet: slå "Lokalt API" til under Indstillinger, installér pluginnet, og sæt token ind i en af GoXLR Studio-tasterne.

---

### English

- **Plugin for Elgato Stream Deck – with status:** keys light up when what they control is on (e.g. red when the mic is muted, or when a profile or EQ preset is in use). The dials on Stream Deck + control a channel's volume and mute. Get `GoXLR-Studio.streamDeckPlugin` below or from the Stream Deck page in the app and double-click it.
- **Home Assistant:** ChatMix, mic limiter, "Game mode active" and a "Save audio clip" button.
- **Phone remote:** ChatMix, limiter and "Save audio clip".
- **Clean voices in the chat** tells you if the Chat output isn't running at 48 kHz.
- The diagnostics report shows which of the new features are switched on.
- New README pictures of Sampler, GoXLR settings and ChatMix.

**What you need to do:** Nothing. To use the Stream Deck plugin: switch on "Local API" under Settings, install the plugin and paste the token into one of the GoXLR Studio keys.

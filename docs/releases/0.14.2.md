## GoXLR Studio 0.14.2

- **Ren mikrofon virker nu også i Discord.** Windows sendte Discords optagelse uden om renseren. Discord og andre stemmeprogrammer (Teams, Zoom) optager i Windows' kommunikationstilstand, og EQ-motoren var kun sat op til almindelige optagelser. Nu sættes motoren på mikrofonen til alle tre slags optagelser: almindelig, kommunikation og rå. Den oprindelige indstilling gemmes og sættes tilbage, hvis du fjerner Ren mikrofon.
- **Testen ser selv efter.** Når Ren mikrofon sættes på eller testes, åbner appen en almindelig optagelse, en optagelse som Discords og en rå optagelse fra Chat Mic. For hver ser den, om renseren bliver indlæst. Afviser Windows optagelser med de nye tilstande, ruller appen selv tilbage, så mikrofonen altid virker.
- **Tjekket ser, om Discord går uden om renseren.** Pluginnet tæller, hvor mange optagelser det renser. Optager flere programmer fra Chat Mic, end der bliver renset, får du en advarsel, der også siger, hvad du kan prøve i Discord. Ellers står der "✓ Discords optagelse bliver renset".
- **Nedbrud i Windows' lydproces rettet.** Når indstillingerne ændredes, mens der blev optaget, kunne Windows' lydproces (audiodg.exe) gå ned. Pluginnet bliver nu i hukommelsen, indtil lydprocessen stopper.
- **Stemmeisoleringen starter hurtigere,** når indstillingerne ændres. Netværket indlæses kun én gang og deles af alle optagelser.
- **Indstillingerne skrives mere robust.** config.txt skrives kun, når den er ændret. Er filen låst et øjeblik, prøves der igen. Lykkes det ikke, vises fejlen i stedet for at forsvinde.
- Knappen "Opdatér" vises nu også på engelsk.

**Det skal du gøre:** Åbn Mikrofon → Ren mikrofon, og tryk "Opdatér". Windows beder om administrator-adgang, og lyden afbrydes et par gange under testen. Genstart derefter Discord helt (også fra bakken). Start et opkald eller "Mikrofontest", og se, at tjekket viser "✓ Discords optagelse bliver renset". Står der ✗, så tryk "Kopiér tjek" og send teksten.

### English

- **Clean mic now works in Discord too.** Windows sent Discord's recording around the cleaner. Discord and other voice apps (Teams, Zoom) record in Windows' communications mode, and the EQ engine was only set up for normal recordings. Now the engine on the mic is set up for all three kinds of recordings: normal, communications and raw. The original setting is saved and put back if you remove Clean mic.
- **The test checks for itself.** When Clean mic is put on or tested, the app opens a normal recording, one like Discord's and a raw one from Chat Mic. For each, it checks whether the cleaner is loaded. If Windows refuses recordings with the new modes, the app rolls back by itself, so the mic always works.
- **The check sees whether Discord goes around the cleaner.** The plugin counts how many recordings it cleans. If more programs record from Chat Mic than are being cleaned, you get a warning that also says what to try in Discord. Otherwise it shows "✓ Discord's recording is cleaned".
- **Crash in Windows' audio process fixed.** Changing the settings while recording could crash Windows' audio process (audiodg.exe). The plugin now stays in memory until the audio process stops.
- **Voice isolation starts faster** when the settings change. The network is loaded only once and shared by all recordings.
- **The settings are written more reliably.** config.txt is only written when it changed. If the file is locked for a moment, it is tried again. If that fails, the error is shown instead of being lost.
- The "Opdatér" button now shows in English too ("Update").

**What you need to do:** Open Mic → Clean mic and press "Update". Windows asks for administrator access, and the sound stops a few times during the test. Then restart Discord completely (also from the tray). Start a call or "Mic Test", and check that it shows "✓ Discord's recording is cleaned". If it shows ✗, press "Copy check" and send the text.

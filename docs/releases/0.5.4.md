## GoXLR Studio 0.5.4

**Nyt: Dansk og engelsk.** Appen kan nu bruges på engelsk, så din ven eller andre uden for Danmark også kan bruge den. Den følger Windows' sprog: dansk Windows giver dansk, ellers engelsk. Du kan skifte under **Indstillinger → Sprog / Language**. Bakke-menuen og beskederne over spil følger med.

**Nyt: Eksportér og importér alle EQ-presets.** Under Presets på Afspilnings-EQ-siden:
- **Eksportér alle presets** gemmer dem i én fil, som backup eller til en ven.
- **Importér** læser filen. Presets lægges ved siden af dine egne og overskriver aldrig noget.

**Det skal du gøre:** Ingenting. Appen opdaterer sig selv, og står din Windows på dansk, er alt som før.

---

### English

**New: Danish and English.** GoXLR Studio now speaks English too. It follows your Windows language (Danish Windows → Danish, anything else → English). Change it under **Settings → Sprog / Language**. The tray menu and the on-screen messages follow along.

**New: Export and import all EQ presets.** Under Presets on the Playback EQ page:
- **Export all presets** saves them in one file, as a backup or for a friend.
- **Import** reads the file. Presets are added next to yours and never overwrite anything.

**What you need to do:** Nothing. The app updates itself.
